# sprites-demo

A small playable demo of `@mise/react`'s asset preloading (`usePreload`) and
engine-time sprite animation (`AnimatedSprite`):

- a loading screen with a real progress bar (throttle your network in
  devtools to watch it fill),
- a character you walk around with WASD / arrow keys, whose walk cycle plays
  while moving and drops to an idle bob when still,
- spinning coins to collect.

## Run

```sh
pnpm install        # from the repo root
pnpm --filter sprites-demo dev
```

Then open the printed URL (default http://localhost:5173).

`pnpm --filter sprites-demo build` produces a production build;
`pnpm --filter sprites-demo preview` serves it.

## Assets

All PNG spritesheets in `public/assets/` are generated by
`scripts/generate-assets.mjs` (a dependency-free PNG encoder), so there is no
copyrighted art. Regenerate them with:

```sh
pnpm --filter sprites-demo generate-assets
```
